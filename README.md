# \# Тестирование приложения BooksCollector

# 

# Проект содержит набор автотестов для класса `BooksCollector`, написанных на фреймворке \*\*pytest\*\*. Тесты проверяют логику добавления книг, управление жанрами, возрастные рейтинги и работу со списком избранного.

# 

# \## Описание тестов

# 

# В рамках проекта реализованы следующие проверки:

# 

# \### 1. Добавление книг (`add\_new\_book`)

# \*   \*\*Параметризованный тест на валидные названия\*\*: проверка граничных значений длины названия (1 символ и 40 символов).

# \*   \*\*Параметризованный тест на невалидные названия\*\*: проверка того, что книги с пустым названием или названием длиннее 40 символов не добавляются.

# \*   \*\*Защита от дублей\*\*: проверка того, что нельзя добавить одну и ту же книгу дважды.

# 

# \### 2. Управление жанрами (`set\_book\_genre`, `get\_book\_genre`)

# \*   \*\*Установка жанра\*\*: проверка успешного присвоения жанра существующей книге.

# \*   \*\*Получение жанра\*\*: проверка корректности возвращаемого жанра по имени книги.

# \*   \*\*Фильтрация по жанру\*\*: получение списка книг определенного жанра (`get\_books\_with\_specific\_genre`).

# 

# \### 3. Возрастные рейтинги (`get\_books\_for\_children`)

# \*   \*\*Детский список\*\*: проверка, что в список для детей попадают только книги с «безопасными» жанрами.

# \*   \*\*Исключение взрослых жанров\*\*: проверка того, что книги с жанрами "Ужасы" и "Детективы" не попадают в детский список.

# 

# \### 4. Избранное (`favorites`)

# \*   \*\*Добавление в избранное\*\*: проверка успешного добавления книги из общего списка в избранное.

# \*   \*\*Удаление из избранного\*\*: проверка корректного удаления книги из списка.

# \*   \*\*Защита от дублей в избранном\*\*: проверка того, что книгу нельзя добавить в избранное дважды.

# 

# \## Инструменты

# \*   \*\*Python 3.11.9\*\*

# \*   \*\*pytest\*\* (использование параметризации)

# 

# \## Запуск тестов

# Для запуска тестов выполните команду:

# 

# pytest -v tests.py
