# Тестирование приложения BooksCollector

Репозиторий содержит набор автотестов для учебного приложения **BooksCollector**. Тесты написаны на языке **Python** с использованием фреймворка **pytest**.

## Описание проекта

Класс `BooksCollector` предназначен для управления библиотекой книг. Он позволяет добавлять книги, устанавливать им жанры, фильтровать по категориям (в том числе по возрастному рейтингу) и работать со списком избранного.

## Реализованные тесты

Все тесты разработаны по принципу **атомарности**: каждый тест проверяет ровно один метод, используя прямой доступ к атрибутам класса для подготовки данных и проверки результата.

### 1. Добавление книг (`add_new_book`)
*   **test_add_new_book_add_two_books**: позитивная проверка добавления двух книг.
*   **test_add_new_book_with_valid_name_is_added**: параметризованный тест границ названия (1 и 40 символов).
*   **test_add_new_book_with_invalid_name_is_not_added**: параметризованный тест на некорректную длину (0 и 41+ символ).
*   **test_add_new_book_double_add_is_not_possible**: проверка защиты от дубликатов в коллекции.

### 2. Работа с жанрами
*   **test_set_book_genre_add_genre_to_book**: проверка успешной установки жанра из списка допустимых.
*   **test_get_book_genre_returns_correct_value**: изолированный тест метода получения жанра конкретной книги.
*   **test_get_books_genre_returns_dictionary**: позитивный тест на возврат полного словаря коллекции.
*   **test_get_books_with_specific_genre_get_comedy_books**: проверка фильтрации книг по жанру.

### 3. Возрастной рейтинг и фильтрация
*   **test_get_books_for_children_returns_only_valid_books_list**: объединенный тест, проверяющий включение разрешенных и исключение запрещенных (Ужасы, Детективы) жанров для детей.

### 4. Избранное
*   **test_add_book_in_favorites_added_successfully**: добавление существующей книги в список избранного.
*   **test_delete_books_from_favorites_deleted_successfully**: удаление книги из списка.
*   **test_add_book_in_favorites_double_add_is_not_possible**: проверка защиты от дублирования в избранном.
*   **test_get_list_of_favorites_books_returns_correct_list**: тест геттера для получения списка избранного.

## Запуск тестов

Для запуска всех тестов с подробным выводом:
```bash
pytest -v tests.py
